# 实验方案：污染物 X 通过 ROS 介导促进过程 Y

## 1. 科学问题与假设

本研究旨在证明污染物 X（溶于 DMSO）通过氧化应激（ROS）介导，促进微生物体系中的目标生物学过程 Y（以转化频率表征）。
预期结论：X 引起 ROS 升高，进而介导过程 Y 增强。

## 2. 实验设计

### 2.1 实验分组

| 组别 | 处理条件 | 平行数 |
| --- | --- | --- |
| 对照组 | 不加 X | 3 |
| 处理组 | 加入污染物 X（DMSO 溶解） | 3 |

说明：每组设置三个平行样品。未另设溶剂对照。

### 2.2 暴露与测定

处理 24 h 后测定：
1. ROS 水平（荧光探针）
2. 过程 Y 的转化频率

若处理组相对对照组 ROS 升高且转化频率升高，则认为 ROS 介导了 X 对过程 Y 的促进作用。

### 2.3 重复

每组三个平行。未区分生物重复与技术重复。

## 3. 统计分析

组间比较采用 t 检验，p<0.05 为显著。未预先说明实验单位。

## 4. 预期结果

处理组 ROS↑、转化频率↑，据此证明污染物 X 通过 ROS 介导促进过程 Y。
