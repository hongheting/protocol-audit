- **时间**：2026-10-25T21:36:13+08:00
- **版本**：`protocol_audit.__version__ = "0.1.2.1"`（= 0.1.2 + reliability patch）

## 改了什么

1. `llm_client.py`：回传/记录 `finish_reason`、`max_tokens`；新增 `is_length_truncated`、`looks_like_truncated_json`。
2. `llm_parse.py`：
   - 检测 `finish_reason=length` / completion_tokens≥max_tokens / JSON 明显截断；
   - **一次**扩容重试（8192 → 16384），purpose=`design_extract_expand_retry`；
   - 仍失败：`ok=False`、`hard_fail=True`、`design_extract=None`，**不再**把 JSON 失败标成 ok；
   - 新增 `LLMParseError`；`allow_heuristic_fallback` 默认 False。
3. `pipeline.py`：真实 LLM 解析失败时 **raise LLMParseError**，禁止「启发式回退却伪装 parse 成功」。
4. `report.py` / CLI：仅版本串改为 `V0.1.2.1`（注明可靠性补丁；科学 Prompt 未改）。
5. 单测：`tests/test_llm_parse_reliability.py`（mock：截断→扩容成功；双次失败 hard_fail；pipeline 抛错）。
