# 实验方案：污染物 X 对过程 Y 的处理效应（探索性）

## 1. 科学问题与目标层级

研究目的：初步探索污染物 X 是否影响模式菌株中过程 Y（转化频率）。
研究目标层级：探索性 / 处理效应（不主张分子介导机制）。
假设（备择）：相对溶剂对照，X 处理改变转化频率。

## 2. 实验设计

### 2.1 实验单位与重复

实验单位：独立培养批次（独立接种、独立制备的培养物）。
每组 **3 个独立生物重复**（独立批次）；每个样品测定时设 3 个技术复孔，技术复孔仅用于降低测定噪声，**不作为独立样本进入组间推断**。

### 2.2 分组与对照

| 组别 | 处理条件 | 独立生物重复 n | 对照作用 |
| --- | --- | --- | --- |
| 空白对照 | 培养基，无溶剂、无 X | 3 | 排除基线漂移 |
| 溶剂对照 | 等体积 DMSO，终浓度与处理组一致（volume-matched） | 3 | 排除溶剂本身效应 |
| 处理组 | 污染物 X（DMSO 溶解，溶剂体积与溶剂对照匹配） | 3 | 检验处理效应 |

### 2.3 终点指标

主要终点：转化频率（与科学问题对齐）。
次要终点：OD600（生长，用于排除毒性混杂的描述性检查）。
不测定 ROS；本方案不声称氧化应激介导。

### 2.4 随机化

批次处理顺序随机化；测定按盲样编号进行。

## 3. 统计分析

预先计划：以独立生物重复为统计单位；主要比较溶剂对照 vs 处理组（转化频率）。
方法：Welch t 检验或等价非参数方法；技术复孔先取均值再进入统计。
显著性阈值 α=0.05；本探索性研究不做多重终点的机制外推。

## 4. 结论边界

若仅观察到处理组与溶剂对照的转化频率差异，结论限于「在本体系中 X 与过程 Y 变化相关的处理效应」，不外推至实际环境普遍性，不主张 ROS 或其它机制介导。
