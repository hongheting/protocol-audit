## 需要决策的问题

1. **设计解析 `max_tokens=8192` 触顶**：Trial1 extract 截断致 JSON 失败并启发式回退，CE 外推行标题质量下降。是否在下一小版本将 extract 的 `max_tokens` 提高到 12288/16384，或对截断自动重试一次？本轮按「非严重」未改行为。
2. **LLM 与结构规则重复 finding**：Trial2 体积（F04/F09）、鸡尾酒（F05/F10）双条。是否加强 `merge_findings` 去重阈值，还是保留「规则硬闸 + LLM 复述」双轨？
3. **材料批次限制**：当前以 needs_info「平行独立性」追问；是否要在未见「多批次」字样时直接 confirmed「单批次制备限制外推」？
4. **Plan A 文案嵌套**：`处理分配单位（处理分配单位（容器））` 来自通用模板拼接。是否做纯文案去重（仍禁止写回 Trial1 专名）？
5. **成本核算**：日志已有 token，无人民币单价。是否补一张智谱 Coding 单价表以便回归报告自动估价？
6. **Trial1 工程主张抽取**：启发式路径下 EXTRAP 行有时抓到日程句。是否仅在 LLM extract 成功时启用 EXTRAP 行，失败则用原文关键词窗？
