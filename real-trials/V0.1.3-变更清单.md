## 本轮改了什么（按用户六项）

### 1. P0 Plan A blocker 覆盖校验（`optimizer_a.py`）
- 每个 `confirmed` + `severity=blocker` 建立 **finding → action** 映射：`blocker_action_map[]` 含 `finding_id` / `action` / `problem` / `verification` / `change_note_id` / `covered` / `uncovered_reason`。
- 未覆盖时用 finding.`fix` 合成动作；无 `fix` 则占位并标 **`optimizer_incomplete=true`**，`completeness_note` 写明原因，**不得**宣称 Plan A 完整。
- 扩展动作匹配：空间/台面混杂、助剂/保护剂/载体（不止「助溶剂」）。
- units 缺失时从 findings 文案推断「水槽/挂板」等分配单位（避免嵌套「处理分配单位（处理分配单位）」）。

### 2. 「代表单元」整组补水/处理（`rules_structural.py`）
- 新规则 `structural_representative_unit_dosing`。
- 识别代表盆/代表单元指导整组补水等；检查逐盆监测、校准、暴露一致性表述。
- **默认 `needs_info`**，不直接判 confirmed 伪重复；附追问。

### 3. 单批次材料 CE + 追问（`rules_structural.py` + `claim_evidence.py`）
- 新规则 `structural_single_batch_material`：`needs_info`，不自动升 blocker。
- 区分实验单位重复 vs 独立制备批次；跨批次/推广主张时 CE gap + clarifying question。
- `rules.py` 合并结构规则产生的追问。

### 4. 外推严重度（`rules_structural.py` + `adjust_extrapolation_severity`）
- Schema 无 `major`：文档约定 **major ≡ `high`**。
- 默认 major/high；核心主张 + 短周期/简化证据足以阻断主结论 → `blocker`。
- 「潜在应用 + 明确限制」→ 不机械升级（规则可不产出；LLM 条后处理不升 blocker）。

### 5. finding 软去重改造（`llm_review.merge_findings`）
- **保留**疑似重复原始 finding；标注 `duplicate_of` / `duplicate_group` / `duplicate_reason` / `duplicate_relation`（`true_duplicate` | `similar_different_mechanism` | `none`）。
- 展示可归组，不丢来源/位置/严重度/证据。
- 宽主题「混杂」 alone 需标题重叠才算真重复，否则标相似异机制。

### 6. Schema / 报告装配 / 版本
- `audit-report.v0.2.schema.json`：Finding 重复关系字段；Optimizer 的 `blocker_action_map` / `optimizer_incomplete` / `completeness_note`；ChangeNote 的 `solves` / `verification`。
- `report.py`：先 Plan A（保留 `rule_id`）再剥离内部键；保留 duplicate_*；boundary 引擎串 `V0.1.3`。
- `locators.py`：`docx`→正式 MIME，避免追问 locator 校验失败。
- `claim_evidence.py`：容忍非 dict 假设噪声；单批次外推 gap 模板。
- **保留** V0.1.2.1 截断扩容重试逻辑（`llm_parse` / `llm_client` / `pipeline` 未回退）。
