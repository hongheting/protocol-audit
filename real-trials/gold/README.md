# Trial 1 Gold Standard（评测专用）

## 用途
本目录存放真实方案 Trial 1 的人工标注标准答案，仅用于：
- 对照引擎输出打分（召回 / 误报 / 分级 / Plan A 对准度）
- 回归与验收，不作为产品能力指标的「问题数量」计数器

## 严禁
1. **禁止**将本目录任何内容写入生产 Prompt、system message 或 few-shot 示例。
2. **禁止**针对 `trial1.docx` 硬编码审查结论。
3. 评测脚本可读本目录；解析 / 审查模块的运行时依赖不得 import 本目录。

## 文件
- `trial1.gold.json`：机器可读标准答案（核心缺陷、次要问题、不得误报项）。

## 评分要点（首要指标）
能否识别**影响研究结论成立的关键缺陷**（尤其 G1 水槽–UV 混杂、G2 伪重复），而不是 finding 条数。
Plan A 必须指向真正证据缺口（水槽/容器层面独立重复或主张降级、助溶剂对照、2×2 交互、破坏性测定设计、机制/工程外推收紧），不得仅靠更换统计模型掩盖水槽层面独立重复问题。
