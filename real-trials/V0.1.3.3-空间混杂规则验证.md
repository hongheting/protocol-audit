## 1. Trial 5 回归案例（独立阅读）

原文要点：

> 为便于日常维护，**容器按处理组集中摆放在同一实验台的不同区域**。各容器在试验开始时编号，**位置在 28 d 期间保持不变**。各组采用相同光照时长、曝气强度和补水规则。

| 检查项 | Trial 5 情况 | 判断 |
|--------|--------------|------|
| 处理分组是否与位置绑定 | 是：按处理组集中分区摆放 | 存在处理×空间绑定 |
| 有无随机化/轮换 | 否：位置 28 d 固定 | 无解耦 |
| 位置差异是否可能影响主结论 | 可能（微气候、光照边缘、人员扰动、气路邻近） | 对附着类终点有潜在影响 |
| 期望严重度 | confirmed / high～blocker（评价金标准 G1） | **但**需结合终点敏感性与是否声明环境均匀 |

## 3. 若扩写关键词规则的跨体系评估

候选模式（示意，**本轮未写入代码**）：

- `按处理(组)?集中摆放` + `位置…(保持不变|固定)`
- `同[一]?处理…同[一]?(区域|台面|层架)` + 无随机/区组声明

| 体系 | 适用性 | 误报风险 |
|------|--------|----------|
| 微宇宙/水槽挂板（Trial1/5） | 高 | 中：若文中写「集中摆放」但同时声明区组随机或环境监测均匀，关键词易过杀 |
| 盆栽台面（Trial3） | 中（已有台面×水分规则） | 与代表盆/台面规则重叠 |
| 吸附摇床锥形瓶（Trial2） | 低 | 「分区」少见；若把「同一摇床」当空间混杂易误报 |
| 反应器/连续流（Trial4） | 低～中 | 「固定位置」常指管路，不等于处理绑定 |

**结论：** 仅凭关键词升 **blocker** 误报不可控；需要「绑定证据 + 无随机/区组 + 终点可能受环境影响」三元条件，接近 LLM 判断而非常短正则。

## 4. 本轮决定

**本轮不纳入新的空间/台面分区混杂确定性规则。**

理由：

1. 无法在不堆专案正则的前提下形成跨体系、误报可控的 blocker 规则。
2. 用户明确：不得仅凭关键词自动判 blocker。
3. V0.1.3.3 已修复审查侧截断扩容重试；空间混杂应交由 **真实 LLM 审查**（可靠性修复后）覆盖，并以 Trial 5 重跑验证。
4. 现有 `structural_position_confound` 保持不动（避免为 Trial5 临时改写过拟合）。

若 Trial 5 重跑后 LLM 仍稳定漏报 G1，再单独立项设计「结构化字段」（摆放方式 / 随机化声明）驱动的规则，而非关键词 blocker。
